FrenchyBot

Guide d'integration du chatbot

Methode 1 : Widget flottant (recommande)

Une bulle de chat apparait en bas a droite de votre site. C'est la methode la plus simple et la plus courante.

<!-- FrenchyBot Widget -->
<script src="https://bot.frenchycompany.fr/api/v1/embed.js.php?token=VOTRE_TOKEN"></script>
Remplacez VOTRE_TOKEN par le token public de votre chatbot, disponible dans l'administration.

Methode 2 : Iframe integre

Le chatbot est integre directement dans une page de votre site, par exemple une page de contact.

<iframe
    src="https://bot.frenchycompany.fr/api/v1/chat.php?token=VOTRE_TOKEN&mode=inline"
    width="100%"
    height="600"
    frameborder="0"
    style="border: none; border-radius: 12px;">
</iframe>

Methode 3 : Landing page plein ecran

Le chatbot occupe toute la page. Ideal pour une page d'estimation ou un parcours dedie.

<iframe
    src="https://bot.frenchycompany.fr/api/v1/chat.php?token=VOTRE_TOKEN&mode=fullpage"
    width="100%"
    height="100%"
    frameborder="0"
    style="position: fixed; inset: 0; border: none; z-index: 9999;">
</iframe>

Configuration avancee

Vous pouvez controler le widget par JavaScript apres son chargement :

// Ouvrir le chatbot programmatiquement
window.FrenchyBot.open();

// Fermer le chatbot
window.FrenchyBot.close();

// Verifier si le chatbot est ouvert
window.FrenchyBot.isOpen();
